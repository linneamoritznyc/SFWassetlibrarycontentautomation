# SFW brand: colours, fonts, logo

From the 2026 Soil Food Web Brand Style Guide (PDF) and the 2026 Foundation Brand
Color Guidelines (doc), both shared by Linnea on 24 Oct 2026. Linnea calls the style
guide "our old one", so where the two differ, the colour guidelines win.

## Colours

| Name | Hex | Use |
|---|---|---|
| Soil Brown | `#4F3433` | Headlines, body text when not black, dividers. Safest: brown on cream. |
| Regenerative Green (Food Web Green, old) | `#59A66C` | Section headers, highlights, icons, pull quotes |
| Food Web Green (suggested new) / Classic Green | `#156826` | The deep green of the guide's page headers; backgrounds and buttons |
| Water / Education Blue | `#3780B8` | Data, education, links, secondary buttons |
| Cream | `#F4F1EA` | The main neutral. Use it instead of white wherever possible. |
| Warm Sand | `#D8C3A5` | Content blocks, panels |
| Natural Tan | `#C89B7B` | Secondary background (style guide) |
| Mist Blue | `#A7C6D9` | Secondary data, charts |
| Harvest Gold | `#C9A227` | Primary CTAs, donations, key stats. Never more than 10-15% of a layout. |
| Legacy Mulberry (Dr. E's purple) | `#6B4C7A` | Dr. Elaine only: founder quotes, memorial, legacy programmes. Max 10%, never a CTA, never with gold. |

Mix: about 60% neutral (cream, sand), 25% primary (brown, green, blue), 10% accent,
5% purple only when it applies. No more than 3 brand colours in one small graphic.
No neon, no saturated purple, gradients only if subtle and natural. Avoid green or
gold text on cream unless it is bold; avoid blue on green. WCAG AA contrast minimum.
"If a design feels like a tech startup, we have gone too far."

CLAUDE.md adds: cream works as a shape on a green or photographic background.

## Fonts

- **Montserrat**: headlines.
- **Pathway Gothic One**: condensed caps for labels and section titles (the guide's page headers).
- **Source Sans Pro** (now Source Sans 3): body text.

All three are free Google Fonts (OFL).

## Logo

- Always use the approved artwork; never recreate, recolour, tilt, stretch or add effects.
- Clear space around the circle at least the height of the "S" in SOIL.
- Minimum 140 px wide on screen, 1.5 in printed.
- On photos or colour, use the white version or the version with the drop shadow; keep
  strong contrast and avoid busy backgrounds. Avoid solid black and other dark backgrounds.

## Images

Use only images we have the rights to (own photos, partner permission, or an open
licence that allows commercial use). The style guide's own sample imagery is stock;
CLAUDE.md's rule (real SFW photos, microscopy, credited open-licence photos, no stock,
no AI) is stricter and wins.
